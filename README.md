# RPN Calculator - C++ 逆波兰表示法计算器

## 项目描述
基于C++实现的命令行逆波兰表示法计算器，支持基本数学运算和栈操作。逆波兰表示法（RPN）是一种不需要括号的数学表达式表示方法。

## 功能特性
- **基本运算**: 加法(+)、减法(-)、乘法(*)、除法(/)
- **栈操作**: 
  - `show`: 显示当前栈内容
  - `clear`: 清空栈
  - `pop`: 弹出栈顶元素
- **错误处理**: 除零错误、栈操作错误、无效输入检测
- **用户友好**: 交互式命令行界面
- **完整文档**: 使用Nimib生成的HTML使用手册
