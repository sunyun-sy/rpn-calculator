简介

逆波兰表示法（Reverse Polish Notation，RPN）是一种数学表达式表示法，其中运算符位于操作数之后。与传统的中缀表示法相比，RPN 无需括号即可明确运算顺序。

主要特点

  • 无歧义：无需括号即可明确运算顺序
  • 高效计算：适合栈式计算器实现
  • 简单直观：操作顺序自然流畅

基本概念

什么是 RPN？

传统中缀表达式：(5 + 3) × 2
RPN 表达式：5 3 + 2 ×

核心组件

  • 操作数栈：存储输入的数字
  • 运算符：对栈顶元素进行运算
  • 显示区域：实时显示当前栈状态
